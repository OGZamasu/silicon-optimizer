The party trick

Run AI that looks way too big for your Mac.

Some big AIs are built like a huge team of specialists, and each word only needs a few of them. The app can keep just those specialists in memory and grab the rest from disk the moment they're needed. Exact same answers — a fraction of the memory.

The normal way
19.0 GB
The app's way
5.32 GB

The trade-off is speed: reading from disk makes the AI respond slower, especially on long prompts. The app tells you exactly how much slower before you switch it on — not after you're stuck waiting.

This trick needs a special build of the llama.cpp engine. The app checks the one you have and simply hides the option if it can't do it, instead of failing mysteriously.

What it does

No Terminal. No settings maze. No math homework.

Knows what your Mac can handle

It reads your Mac's real specs — chip, memory, storage — and tells you what fits before you download. If something doesn't fit, it lists exactly what to change and how much each change saves.

Picks the AI for you

One button. The app ranks every model it knows against your machine and picks the strongest one that actually runs at a decent speed. You can always override it.

A chat that actually does things

The Chat tab runs DeepSeek Harness on your local AI: it can browse the web, read and edit files in a folder you choose, and run commands — always asking you first. Not just talk.

Makes images too

FLUX and other image AIs run locally. The app tells you whether a render fits in memory before you start it — not at 95%, after minutes of waiting.

Any model, not just a menu

Search all of Hugging Face — the internet's library of free AI models. The app reads a tiny slice of any model's file and gives you a full verdict before you download gigabytes.

Stays out of your way

Lives in the menu bar: what's loaded, how fast it's running, memory at a glance. Downloads survive bad Wi-Fi and pick up where they stopped.

The fine print

What's solid, and what's still rough.

Everything on this page is a real measurement, not marketing. In the same spirit, here's what a young app hasn't finished yet — so you know exactly where you stand.

  • Speed predictions start from one Mac. They're tuned on an M3 Max; other chips use published specs until you run the built-in one-minute speed test, which tunes them to yours.
  • macOS will complain once. The app isn't notarized by Apple yet, so the first launch needs one command to approve it (shown below). Building from source skips this entirely.
  • The big-model trick needs a special engine. Expert streaming isn't in standard llama.cpp yet. The app checks your build and hides the option if it can't do it.
  • MLX support is early. Apple's MLX engine works, but you have to point the app at a model folder yourself for now.
  • Multi-part downloads are untested. Models split across several files are planned and checked correctly, but the actual multi-file download hasn't been exercised yet.

Get started

Running in about two minutes.

1 · Easiest: Homebrew

brew tap OGZamasu/tap
brew install --cask silicon-optimizer

2 · Or download the app directly

# macOS blocks apps from new developers once. After dragging
# it to Applications, approve it with:
xattr -d com.apple.quarantine "/Applications/Silicon Optimizer.app"

3 · Or build it yourself

# Needs Xcode 16+ on an Apple Silicon Mac (macOS 14 or later)
git clone https://github.com/OGZamasu/silicon-optimizer
cd silicon-optimizer
Scripts/build-app.sh --release
cp -R "build/Silicon Optimizer.app" /Applications/

4 · Install an engine — the thing that does the AI math

brew install llama.cpp                              # recommended
python3 -m venv ~/.silicon-mlx
~/.silicon-mlx/bin/pip install mlx-lm               # optional — Apple's MLX

5 · Optional: connect Claude or ChatGPT

Scripts/install-mcp.sh --configure-claude

The app finds engines on its own, even inside a Python virtual environment. Settings shows what it found and what each one can do.
